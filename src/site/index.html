01

If you tapped a card to get here

You're holding a printed card with a chip in it. The chip carries two things: where this project lives, and what it is.

The second part matters more than it sounds. Addresses rot — usernames get freed, domains lapse, hosting moves. When that happens the tap doesn't fail, it lies: someone else's page, served from the address printed on your object. So the card states what it is, on the card, in plain text, where no server gets a vote.

InkThe identity, printed. Immutable, decade-rated, readable by a person. The primary record.
Chip · idThe same identity in plain text on the tag. Survives the address dying.
Chip · urlWhere it currently lives. Disposable, rewritable forever.

The layer you can rewrite carries the thing that changes. Never the other way round.

02

Wish It Better

A portable standard for building small tools that measurably improve on a loop, in public, with the history as the proof.

A project joins by committing one small file at its root naming where it came from and what came from it. Those two fields are edges — a crawler can walk them and render the whole network with nobody maintaining a directory. No registry, no server, no authority. Including us.

The part that compounds is the amendment clause: an adopter who hits a real scar amends the standard, and every other adopter inherits the fix. An amendment has to come from something shipped, never from a theory — and it should prefer deleting a rule to adding one.

Three verbs, three commitments
  • Create

    The project exists. Private. Nothing exposed. An agent can do this for you unasked.

  • Publish

    The page goes live. You decide, explicitly.

  • Share

    It joins the network. You decide, explicitly.

The default rung is the safe one and you can't skip one by accident. Publishing has no undo.

Card Studio

The tool that prints the cards and programs the chips.

Design a card, get the geometry exactly right for your tray, and print it. The browser version does the design and the print-exact PDF; the desktop app adds the printer and the card reader. Python standard library only — it runs from a clean clone with no install step.
