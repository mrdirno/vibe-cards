How it works

Design itBoth sides, laid out at the exact size of a real card.
Program itWrite the chip so a phone opens your link when it touches the card.
Print itOn a desktop printer with a card tray. No app, no account, nothing to sign up for.

Books

A book is an ordered set of cards that share a theme. It is a curation, not a format — every card in one is a plain card, and would be that same card if the book did not exist.

Compound Craft

BOOK ONE

Craft cards, each a physical handle to one craft: tap it, get the tool and the template, build the thing. Each card is meant to leave behind something that makes the next one cheaper. Seven cards so far.

The living half

Some card fronts are not pictures — they are rules. A rule fits in a few numbers, and the numbers printed on the card are enough to make the exact same picture again, forever.
