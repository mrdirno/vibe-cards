    Loading order matters
    1. Press Print to tray first — send the job before touching the tray.
    2. The printer asks to initialise: pull the paper output tray OUT and press OK. (closed here = code 1857 / 1851 / 1259)
    3. It then asks for the tray: push the output tray back IN, flush with the operation panel. (left out here = code 1850 / 1855)
    4. Seat both cards, slide the multi-purpose tray in until the arrows line up, then press OK on the printer.

    The output tray is wanted in opposite positions at steps 2 and 3 — out to initialise, in to accept the tray. Follow the printer's screen in order rather than chasing one code, or you will flip between 1857 and 1850. Canon also warns that mounting the tray before it asks can damage the printer, and the tray auto-ejects if it sits too long after the prompt (the job then errors — just re-send).

    Output

    A dry run pushes the job through the real print filters and reads back the raster size, so you can confirm the geometry before any card is at risk.
