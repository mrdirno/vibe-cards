## AI tooling used

Parts of this repository were written with AI coding assistants working under the author's
direction. Disclosing that here, rather than in a commit trailer, is what APA 7th, MLA 9th,
Chicago 17th and COPE all call for: a generative AI system cannot be an author or
co-author, because it cannot hold copyright, take responsibility for the work, or consent
to publication. Tools are acknowledged. Only people are authors.

Measured from this repository's own history on 2026-09-03, across the 209 commits between
2026-08-09 and 2026-09-02:

| Tool named in a commit trailer | Commits |
|---|---:|
| Claude Opus 5 | 135 |
| Claude Fable 5 | 25 |
| Claude Fable 5.1 | 2 |
| Claude Opus 4.8 | 1 |
| **Total commits carrying such a trailer** | **163 of 209 (78%)** |

Those 163 trailers are a mistake this file exists to replace. GitHub renders a
`Co-Authored-By:` trailer as a real co-author on every commit page, and those pages are
crawled, so the effect of 163 of them is to publish a claim that a vendor's model
co-authored the work. It did not. The rule for every commit from here on is in
[`CLAUDE.md`](CLAUDE.md): one author, and this file for the tools.

The trailers already in the published history are left alone. Rewriting published history
is a separate and larger decision, and it belongs to the owner.
